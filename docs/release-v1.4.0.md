# Tom Sakura v1.4.0 · 原始画质择优

适用于 **Windows 10 / 11 x64**。继续保留液态玻璃主题、追番、观看记录和断点续播。

## 下载安装

- **免安装版**：`Tom Sakura-1.4.0-x64-Portable.exe`，退出旧版后直接打开。
- **安装版**：`Tom Sakura-1.4.0-x64-Setup.exe`，按提示完成安装。
- **校验与帮助**：`SHA256SUMS.txt` 和 `使用说明.txt`。发行包尚未签名，Windows 可能提示未知发布者。

## 这一版改了什么

打开 **应用设置 → 默认播放策略 → 画质优先**。下次加载视频时，客户端会比较已有 HLS 候选的高清档和带宽余量，保留自动降档与切源。播放器显示的是实际解码尺寸，而不是源站的“高清”标签。

65 项离线测试通过，打包版实测完成 1920×1080 视频解码。该结果不代表每集都有高清片源；此版本没有导入 Kazumi 社区规则，也没有接入 Anime4K 超分。

截图与使用指引见仓库首页。客户端不托管视频，使用时请遵守来源站点条款及内容权利。
